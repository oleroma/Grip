# Measurements

Evaluated meshes of every object with a Geometry Nodes modifier, read in world space from a headless evaluation of a copy of the file (bpy 5.2.2) [measured]. Size is the bounding box in mm (X × Y × Z), volume in mm³ (signed, from the triangles), NM = number of non-manifold edges, Z = lowest and highest point. `variant` is set to match the scene; everything else is as saved unless the heading says otherwise (`subdivision level` low, `voxel resolution` low). Objects that only exist for reference (`case_front.002`, `reference millwd`) are included because they carry modifiers.

Text marks are missing from these numbers: the file uses Windows fonts that were not available, so marks on bumpers, buttons and triggers produced no geometry (see [11. Method](../11-method.md)).
