# Extensions

Blender extensions used by Grip. Do not edit these by hand: each folder is overwritten
automatically by a GitHub Action in its source repo whenever that repo's main branch changes.

| Folder | Source |
| --- | --- |
| `combi_export/` | https://github.com/oleroma/combi_export |
| `blender-tracking/` | https://github.com/oleroma/blender-tracking |

## Use in Blender

Preferences > Get Extensions > Repositories > Add Local Repository, then point it at this folder.
